One short, funny rant about an everyday annoyance — the family group chat drowned in "good morning" flower images. The program writes the rant to `/output/entry.txt` (176 characters, one text, stdlib only, no network).

## Run

```sh
python3 main.py
cat /output/entry.txt
```
